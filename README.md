Jimmy da Costa Stateri - Online CV
A web-based, interactive version of my professional curriculum vitae. This project serves as a live portfolio piece demonstrating my frontend development skills, code organization, and attention to responsive design.
🔗 View Live CV Here 
🚀 Overview
As a First Class BSc (Hons) Computer Science graduate, I built this digital CV to make my professional background, projects, and technical skills easily accessible to recruiters and fellow developers. It reflects the content of my traditional CV but provides an interactive web experience.
🛠️ Built With
HTML5: Semantic structure for accessibility and SEO.
CSS3: Custom styling, responsive layout (Flexbox/Grid), and print-friendly media queries.
(Optional: Add JavaScript, TypeScript, React, Tailwind, etc., depending on what you actually used)
🌟 Key Features
Responsive Design: Fully optimized for viewing on desktops, tablets, and mobile devices.
Print-Friendly: Configured with @media print CSS so that generating a PDF via the browser yields a perfectly formatted traditional CV.
Clean UI/UX: Minimalist and professional design focusing on readability.
💻 Running Locally
If you'd like to clone this repository and run it on your local machine:
Clone the repository:
git clone https://github.com/jstateri/online-cv.git


Navigate to the project directory:
cd online-cv


Open the index.html file in your preferred web browser, or use a local server (e.g., Live Server extension in VS Code) for the best experience.
